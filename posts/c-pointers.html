C 语言的指针传参到底传了什么？

用两个短函数分清传指针、改变量和改指针本身。

改调用者的整数

void set_value(int *p)
{
    *p = 10;
}

// 在 main 中调用
int x = 3;
set_value(&x);  // x 现在是 10

调用时，&x 求出 x 的地址。函数形参 p 收到这个地址的一份副本。*p 表示该地址处的整数，也就是调用者的 x，所以赋值会改到 x。如果在函数里给 p 本身另赋一个地址，改变的是函数这一份地址。

改调用者的指针

现在调用者有个指针变量 ptr，希望函数让它指向 y。把 ptr 当作要修改的对象，它的类型是 int *，所以它的地址 &ptr 的类型是 int **。

void set_pointer(int **slot, int *target)
{
    *slot = target;
}

// 在 main 中调用
int x = 3;
int y = 8;
int *ptr = &x;
set_pointer(&ptr, &y);  // ptr 现在指向 y
*ptr = 12;             // y 是 12，x 仍然是 3

slot 存着 ptr 的地址，*slot 就是调用者的指针变量 ptr。给 *slot 赋值，改变了 ptr 保存的地址。之后再给 *ptr 赋值，改到的是它现在所指向的 y。

看见星号时，先追一层地址

先确定要改的变量，再看传进去的是谁的地址，最后从形参开始逐层解引用。这里传的是 &ptr，所以解引用一次就到了 ptr。
